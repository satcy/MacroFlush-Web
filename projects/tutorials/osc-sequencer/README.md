# OSC sequencer tutorial files

- `osc-sequencer.json`: MainComposition and Composition2 (1280 × 720, 60 fps, 360 frames). Each contains `SendOscParamsTest`, with keys on `val0`, `val1`, `color` and `pos`. MainComposition has Cue1 / Cue2 / Cue3. Changed custom values are sent with `sendOsc("/" + getCompositionName() + "/" + name, clip[name])`, using `clip.paramNames` and `clip.isNew`.
- `osc-sequencer.maxpat`: Max 8 patch. `udpsend localhost 9000` controls MacroFlush (`/transport/*`, `/composition/open`, `/cue/*`, `/layers/Layer1/visible`). Incoming `udpreceive 9001` goes through `p osc_split_MainComposition_Composition2`: address components 1 and 2 identify the Composition and parameter; `route MainComposition Composition2` controls `gate 2 1`, with unknown names selecting 0. Outlet 1 feeds MainComposition's parameter route; outlet 2 feeds Composition2's. Both use `route /val0 /val1 /color /pos` after the Composition prefix is removed and original values are rejoined. Rename the Max routes and switching messages when renaming a Composition; do not use `/` in names with this splitter.

Both files were updated by the site owner on 2026-11-16 and copied unchanged from `../MacroFlush_Projects/osc_sequencer_sample.json` and `osc_sequencer_sample.maxpat`. No external media or libraries are required. Use MacroFlush app v0.3.19 or later. `getCompositionName()` and `getCompositionId()` were introduced in v0.3.19.

`getCompositionName()` / `getCompositionId()` identify the Composition directly containing the executing Clip, not always the outer root. Renames appear on the next tick; IDs distinguish same-named Compositions; unavailable identity returns an empty string. These Clip APIs also work in the browser Editor and Player, while UDP OSC itself is app-only. Contracts were checked against the adjacent app's `src/core/clipCompositionIdentity.ts`, runtime declarations, documentation and the bundled distributions.

Tutorial images are real browser Editor captures. The keyframe image shows the updated project at frame 120 (val1 holds 8.1328125 from frame 90). The OSC-tab image shows the unchanged incoming control addresses. Native app / Max OSC delivery was not exercised from this repository; Max behavior described in the article is based on the supplied patch connections.
