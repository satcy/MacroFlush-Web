# Advanced tutorial set

Ten site-authored bilingual tutorials with twenty portable V2 projects. IDs and paths are stable; display numbers follow `src/tutorial-categories.js` and are not embedded in project identifiers. Existing Examples, application code and vendor snapshots are untouched.

| Folder | Starter → completed |
| --- | --- |
| composition-reuse | One reference to Card → two references with independent transforms and In points; shared child Composition |
| timeline-mask | Unmasked Prism → Prism masked by hidden transparent text/circle Matte with radius keys |
| cue-performance | Three visual sections, no Cues → Intro none / Loop loop / Outro stop |
| stem-reactive | Synthetic mix only → four attached original synthesized parts, read by audioStem |
| seamless-loop | A 3.3-second period cut to four seconds → a four-second period and integer harmonics |
| shader-stack | Prism alone → Blur / Chromatic / Grade, three Layers Below Effect layers |
| model-product | Original static Bottle GLB and studio → Null turntable, rim light and transparent Canvas title |
| seeded-motion | Per-frame Math.random flicker → stateless indexed numeric hash and time-derived motion |
| alpha-logo | Static opaque-background arcs → transparent reveal keys with a readable hold |
| embed-player | Artwork with fixed hue / single-frame HTML host → hue keys / interactive host and portable web kit |

All compositions use 1280 × 720 and 60 fps. Reuse, Cue and stems are 480 frames; Model is 360; others are 240. Out is excluded. 3D JSON angles remain radians. Runtime code and GLSL are exported from `src/advanced-code.js`; articles and translations are in `src/advanced-tutorials.js`; catalogue and UI descriptions are in `src/advanced-projects.js`.

Regenerate only this set with `node scripts/generate-advanced-tutorials.mjs`, or pass one or more slugs to limit writes. `scripts/tutorial-project-utils.mjs` uses only existing site defaults and Node built-ins. No network downloads, packages or adjacent app installation are needed.

## Original practice material

- `stem-reactive/drums.wav`, `bass.wav`, `other.wav`, `vocals.wav`, `mix.wav`: deterministic eight-second mono PCM 16-bit / 22050 Hz synthesis. Vocals is a synthetic voice-like harmonic tone, not a person. Each component is synthesized separately; the mix combines them. They are **not** HT-Demucs output and do not demonstrate model quality. The completed JSON embeds all four; the starter embeds only the mix. `practice-stems.zip` preserves these exact five WAV files. Attach only the four named parts.
- `model-product/bottle.glb`: original lathed geometry and a contrasting front badge with two PBR materials, generated by `scripts/tutorial-model.mjs`. Static glTF 2.0, embedded buffers, no external textures, required extensions, animations, skins or morphs. The same bytes are embedded in both project JSONs.
- `alpha-logo`: original tutorial arcs, not a replacement or derivative of the MacroFlush logo.

These authored practice assets may be reused and adapted with the tutorial projects. Bundled Player dependencies keep their original license notices.

## Portable host artifact

`scripts/build-tutorial-kit.mjs` builds `dist/projects/tutorials/embed-player/start.html`, `complete.html`, `player-host.js`, the entire unmodified `player/` distribution and `web-kit.zip`. Generated HTML and ZIP are not committed. `src/tutorial-player-host.js` owns the playback clock, progress, pause/seek/reset, hidden-tab pause and pagehide disposal. The starter intentionally draws once. A local HTTP server or static hosting is required; opening file:// is not the supported workflow. No CDN or private GitHub link is needed.

The stored-ZIP writer uses Node only. `scripts/check-tutorial-kit.mjs` verifies CRCs, safe paths, exact Player bytes, both HTML entries and all stem ZIP contents. Both normal and prefixed builds are checked.

## Verification boundary

Project schema, Clip syntax, nested placement/mask references, WAVs, GLB headers and bilingual content are checked locally. Actual Player rendering was checked in Chrome for both variants of all ten projects, including random seeks for deterministic examples. The intentionally unstable random starter is excluded from repeatability expectations. The web kit's actual Play / Pause / Seek / Reset was operated in Chrome.

No native ProRes encode, actual HT-Demucs inference, external hosting publication or third-party model import is claimed by these website checks. Articles describe their supported workflows and distinguish app-only operations with per-step availability badges.
