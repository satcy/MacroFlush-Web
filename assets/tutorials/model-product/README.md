# GLB product tutorial screenshots

Unmodified captures of the real bundled OnlineEditor, loaded through
`/online-editor/?example=advanced-model-product-complete`. Recaptured on 2026-11-17
in Google Chrome through Playwright, 3342 × 2554 pixels (1671 × 1277 CSS viewport,
device scale factor 2). Page-content screenshots contain only the real Editor:
no browser tab bar, address bar, browser sidebar, or desktop chrome is included.
The bundled Editor and site-authored GLB are used with the current twelve-sphere
Orbit Ring, four spatial sine cycles, and blue / magenta / green materials.

- `01-target-parent.jpg`: frame 0; Bottle selected; Target Scene1, Parent Null1, Type Original.
- `02-turntable.jpg`: frame 90; Null1 selected; interpolated rotation Y about 90.25 degrees; keys at 0 and 359.

The Code Editor panel is collapsed through its own Hide Editor button. The
Timeline divider is dragged upward to show every layer and both rotation keys.
Frame 90 is selected through the Timeline position field in Frames mode; Target,
Parent and rotation are checked in the real Inspector before capture. No Editor
distribution, project data, DOM styling, or image content was altered for capture.

Both language editions use the same actual Editor captures with localized captions.
